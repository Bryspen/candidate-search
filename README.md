![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

## Description

Candidate Search This project is a React application that allows users 
to search for GitHub users and display their profiles. It fetches data 
from the GitHub API and displays user information such as avatar, name, 
location, email, company, and bio.
